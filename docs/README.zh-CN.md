# SPDR 机械蜘蛛实验室

Vincent Builds 的第一个可交互三维步态作品。用 AI 辅助编写代码，通过程序化几何构建八足机器人，在浏览器中观察运动参数与步态的关系。

## 已完成

- 八条腿、两节式逆运动学；WebGL 和 Canvas 兼容渲染共用关节坐标。
- 交替、波浪两种相位模式。
- 步速、步幅、抬腿高度实时调整。
- 自由、正面、俯视视角；拖动旋转、滚轮缩放。
- 足端轨迹、线框、暂停、重置、场景截图与展示模式。

## 使用源码包

克隆当前 GitHub 仓库，或下载源码 ZIP。安装 Node.js 22.13 或更新版本，在项目文件夹中打开终端：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。检查和构建：

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

源码包是独立 React/Vite 版本，演示核心代码与当前网站相同，去除了账号、站点部署标识和历史。依赖首次安装需要联网；安装后生成的 package-lock.json 应随你的后续仓库一起提交。

## 视频中怎么介绍

可以说「用 AI 辅助搭建了一个浏览器里的八足机器人步态原型」，展示可操作的参数、轨迹和实际算法代码。

不要说「已经训练出自主机器人」「已经实现真实物理仿真」或「所有代码均由本人手写」。目前没有转向、真实前进、碰撞、地形适应或实体控制。

## 验证

9,216 组数值配置通过：坐标有限、目标可达、腿段长度固定、足端不低于名义接触面、运动周期闭合。测试不证明物理稳定性。

可用测试浏览器无法启动 WebGL，已检查 Canvas 兼容模式的交互画面。WebGL 路径已通过类型检查与构建，尚未在该浏览器视觉验证。手机实机性能未测。
